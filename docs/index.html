What's New

2.0.0 更新亮点

规则引擎全面重构，新增多种规则类型，导出与生成体验同步升级

NEW

规则类型扩充至 11 种

新增「每天必排」「保持课时顺序」「老师不能在指定时间排课」等规则，排课约束更细腻，组合出更贴合真实需求的课表。

NEW

规则支持生效范围

每条规则都能自由指定作用于哪些班级，不同年级、不同学科可采用各自的排课策略，互不干扰。

NEW

导出 CSES 课表

支持导出 CSES v1 / v2 通用课表交换格式，可直接导入 Class Island、Class Widgets 等班级大屏课表软件。

NEW

生成完成系统通知

排课过程无需守候，生成完成后自动推送系统通知，切到别的窗口也不会错过结果。

NEW

课程时间冲突检查

配置上下课时间与活动时间时自动检测时间交叉，及时给出警告提示，避免设置互相冲突。

NEW

生成功能更细致

减少教师连堂、平均分配课程、允许跨上下午连堂、限制教师同时最大上课数量等选项一应俱全。

Get Started

两种方式，即刻开始

选你顺手的方式，几分钟就能跑起来

Developer

方式一 · 从源码运行

  1. 安装 Python 3.9+
  2. 下载解压本项目，终端进入目录
  3. 执行 pip install -r requirements.txt
  4. 运行 python main.py
One Click

方式二 · 安装包即用

  1. 前往 Releases 页面
  2. 下载 Setup.exe 安装程序
  3. 双击安装，桌面生成快捷方式
  4. 或下载 .zip 解压即用
